## Uso de Git

Antes de comenzar a trabajar es recomendable comprobar el estado del repositorio y descargar posibles cambios:

```bash
git status
git pull
```

Para añadir los cambios realizados:

```bash
git add .
```

Crear un commit:

```bash
git commit -m "Descripción de los cambios"
```

Y subirlos al repositorio remoto:

```bash
git push
```

## Clonar el repositorio

Para trabajar con el repositorio desde otro equipo:

```bash
git clone URL_DEL_REPOSITORIO
```

Después:

```bash
cd Programacion-Avanzada
```

## Flujo de trabajo recomendado

Antes de empezar:

```bash
git pull
```

Después de realizar cambios:

```bash
git status
git add .
git commit -m "Descripción de los cambios"
git push -u origin master
```

De esta forma se mantiene actualizado el repositorio local y remoto.
